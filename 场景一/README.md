## 开发流程说明
按照业务规格说明书，进行需求分析、系统方案设计、任务拆解与迭代规划后，按开发任务进行开发、测试
```mermaid
flowchart LR
    A[阶段1：需求解析与对齐] --> B[阶段2：系统方案设计]
    B --> C[阶段3：任务拆解与迭代规划]
    C --> D[阶段4：分迭代开发&单元测试]
    D --> E[阶段5：集成测试&边界异常专项验证]
    E --> F[阶段6：全套交付物整理完善]
    F --> G[阶段7：Demo预演&验收自查]

    %% 回退链路
    B -.发现规格歧义.->A
    D -.设计缺陷回退.->B
    E -.bug/边界不满足.->D
    G -.不满足考核要求.->F & E
```
